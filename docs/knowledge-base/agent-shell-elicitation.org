#+TITLE: agent-shell's Elicitation Switch — Reference
#+STARTUP: overview

Not a project document. This records how agent-shell 0.86.2 decides whether a
session advertises and answers ACP elicitation, as read in its source and
established by runs of it with acp 0.15.1, the versions pinned for the tests in
=Elkfile=, on 2026-10-14.

*What it establishes.* One variable, off by default, switches elicitation on.
agent-shell reads it twice: once while =agent-shell-start= runs, to decide
whether the initialize request advertises form elicitation, and again in the
session buffer each time the AI program sends =elicitation/create=. So a value
bound around =agent-shell-start= advertises elicitation but answers no request,
and a value set in the session buffer afterwards answers requests that were
never advertised; the switch needs both, or a global value. With it on, the
initialize request advertises form elicitation and never url elicitation.
Restarting, reloading or forking a session starts one without the switch.

* One variable switches elicitation on, and it is off by default

=agent-shell-elicitation.el=:

#+begin_example
(defvar agent-shell-elicitation--experimental-feature-enabled nil
  "When non-nil, render `elicitation/create' requests as in-buffer forms.

Off by default while the feature soaks.  With it off the capability
goes unadvertised, so a conforming agent never sends the request.")
#+end_example

* The initialize request reads the switch while agent-shell-start runs

=agent-shell.el=, =agent-shell--initiate-handshake=, builds the initialize
request with:

#+begin_example
             :elicitation-form-capability agent-shell-elicitation--experimental-feature-enabled)
#+end_example

=agent-shell--start= calls =agent-shell--handle= before it returns, and
=agent-shell--handle= creates the client, subscribes to it and calls
=agent-shell--initiate-handshake= in one chain of calls. In the run below, the
switch let-bound around =agent-shell-start= puts =elicitation= in the
initialize request's =clientCapabilities=; the switch set in the session buffer
only after =agent-shell-start= has returned does not.

* The switch on advertises form elicitation and never url

=acp.el=, =acp-make-initialize-request=, adds =elicitation= to
=clientCapabilities= only when a form or url capability is given:

#+begin_example
                                       ,@(when (or elicitation-form-capability
                                                   elicitation-url-capability)
                                           `((elicitation
                                              . (,@(when elicitation-form-capability
                                                     '((form . nil)))
                                                 ,@(when elicitation-url-capability
                                                     '((url . nil)))))))))))))
#+end_example

agent-shell passes no url capability. In the run below, encoded the way acp
writes it to the AI program (=acp--serialize-json=), the capabilities read
="elicitation":{"form":{}}=, with no =url=.

* An elicitation request reads the switch in the session buffer

=agent-shell.el=, =agent-shell--on-request=, hands the request on only while
the switch is on:

#+begin_example
        ((and (equal (map-elt acp-request 'method) "elicitation/create")
              agent-shell-elicitation--experimental-feature-enabled)
         (agent-shell-elicitation--on-create-request
#+end_example

=agent-shell--subscribe-to-client-events= subscribes it through
=acp-subscribe-to-requests= with no =:buffer=, and =acp.el=,
=acp-subscribe-to-requests=, runs each handler with the client's
=:context-buffer=, the session buffer, current. In the run below, an
=elicitation/create= request is handled when the switch is set in the session
buffer, or globally, and not when it was only let-bound around
=agent-shell-start=.

* agent-shell-restart, agent-shell-reload and agent-shell-fork start a session without the switch

=agent-shell.el=, =agent-shell-restart= kills the session buffer, and with it
the switch set there, then starts a new one:

#+begin_example
    (unless (kill-buffer shell-buffer)
      ...
      (user-error "Cancelled"))
    (let* ((default-directory shell-dir)
           (new-shell-buffer (agent-shell--start
                              :config config
                              :session-strategy strategy
                              :session-id session-id
                              :new-session t
                              :no-focus t)))
#+end_example

=agent-shell-reload= calls =(agent-shell-restart :session-id session-id)=.
=agent-shell-fork= starts the new session from the session buffer it was
called in:

#+begin_example
    (let ((new-shell-buffer (agent-shell--start
                             :config config
                             :session-strategy 'new
                             :fork-session-id session-id
                             :new-session t
                             :no-focus t)))
#+end_example

None of the three binds the switch, or sets it in the buffer it starts. In the
run below, a session started with the switch bound around =agent-shell-start=
and set in its buffer, then restarted, reloaded or forked, gives a session whose
initialize request advertises no elicitation and which handles no
=elicitation/create= request. A fork does so although the buffer it is called
in has the switch set.

* The run

Run with =emacs -Q --batch -l el-run.el <directory of the agent-shell, acp and
shell-maker builds> <empty directory>=. It starts each session with a client
running =true=, records the initialize request instead of sending it, answers
yes to the question =agent-shell-restart= asks while the initialize request is
outstanding, and calls the session's request handlers with an
=elicitation/create= request, printing any error a handler signals.

#+begin_src emacs-lisp
;;; el-run.el --- How agent-shell 0.86.2 gates elicitation -*- lexical-binding: t; -*-
(dolist (dir (directory-files (car command-line-args-left) t "\\`[^.]"))
  (add-to-list 'load-path dir))
(require 'agent-shell)
(require 'cl-lib)
(setq default-directory (file-name-as-directory (cadr command-line-args-left)))

(defvar el-run-initialize nil
  "The clientCapabilities of the last initialize request, as acp would send them.")
(defvar el-run-handled nil
  "Non-nil once an elicitation/create request has reached its handler.")

(defun el-run-config ()
  (cons (cons :client-maker
              (lambda (buffer) (acp-make-client :context-buffer buffer :command "true")))
        (agent-shell-anthropic-make-claude-code-config)))

(defun el-run-elicit (buffer)
  "Send BUFFER's session an elicitation/create request; return whether it was handled."
  (setq el-run-handled nil)
  (dolist (handler (map-elt (map-elt (buffer-local-value 'agent-shell--state buffer) :client)
                            :request-handlers))
    (condition-case err
        (funcall handler '((jsonrpc . "2.0") (id . 1) (method . "elicitation/create")
                           (params (mode . "form") (message . "?"))))
      (error (princ (format "  handler error: %S\n" err)))))
  el-run-handled)

(defun el-run-report (label buffer)
  (princ (format "%s\n  initialize clientCapabilities: %s\n" label el-run-initialize))
  (princ (format "  elicitation/create handled: %S\n" (el-run-elicit buffer))))

(defmacro el-run-recording (&rest body)
  `(cl-letf (((symbol-function 'acp-send-request)
              (lambda (&rest args)
                (let ((request (plist-get args :request)))
                  (when (equal (map-elt request :method) "initialize")
                    (setq el-run-initialize
                          (string-trim (acp--serialize-json
                                        (map-nested-elt request '(:params clientCapabilities)))))))))
             ((symbol-function 'agent-shell-elicitation--on-create-request)
              (lambda (&rest _) (setq el-run-handled t)))
             ((symbol-function 'y-or-n-p)
              (lambda (prompt)
                (princ (format "  asked %S; answered yes\n" prompt))
                t)))
     ,@body))

(defun el-run-start-the-ides-way ()
  "Start a session with the switch bound around it and set in its buffer."
  (let ((buffer (let ((agent-shell-session-strategy 'new)
                      (agent-shell-elicitation--experimental-feature-enabled t))
                  (agent-shell-start :config (el-run-config)))))
    (with-current-buffer buffer
      (setq-local agent-shell-elicitation--experimental-feature-enabled t))
    buffer))

(defun el-run-kill (buffer)
  (when (buffer-live-p buffer)
    (let ((kill-buffer-query-functions nil))
      (kill-buffer buffer))))

(el-run-recording
 (let ((buffer (let ((agent-shell-session-strategy 'new))
                 (agent-shell-start :config (el-run-config)))))
   (el-run-report "Switch left off" buffer)
   (el-run-kill buffer))
 (let ((buffer (let ((agent-shell-session-strategy 'new)
                     (agent-shell-elicitation--experimental-feature-enabled t))
                 (agent-shell-start :config (el-run-config)))))
   (el-run-report "Switch let-bound around agent-shell-start" buffer)
   (el-run-kill buffer))
 (let ((buffer (let ((agent-shell-session-strategy 'new))
                 (agent-shell-start :config (el-run-config)))))
   (with-current-buffer buffer
     (setq-local agent-shell-elicitation--experimental-feature-enabled t))
   (el-run-report "Switch set buffer-local after agent-shell-start" buffer)
   (el-run-kill buffer))
 (let ((buffer (el-run-start-the-ides-way)))
   (el-run-report "Switch let-bound around agent-shell-start and set buffer-local after it" buffer)
   (with-current-buffer buffer
     (map-put! agent-shell--state :session '((:id . "session-1")))
     (setq el-run-initialize nil)
     (agent-shell-restart))
   (let ((restarted (seq-find (lambda (b) (and (not (eq b buffer))
                                               (eq (buffer-local-value 'major-mode b) 'agent-shell-mode)))
                              (buffer-list))))
     (el-run-report "The same session after agent-shell-restart" restarted)
     (el-run-kill restarted)))
 (let ((buffer (el-run-start-the-ides-way)))
   (with-current-buffer buffer
     (map-put! agent-shell--state :session '((:id . "session-1")))
     (setq el-run-initialize nil)
     (agent-shell-reload))
   (let ((reloaded (seq-find (lambda (b) (and (not (eq b buffer))
                                              (eq (buffer-local-value 'major-mode b) 'agent-shell-mode)))
                             (buffer-list))))
     (el-run-report "The same session after agent-shell-reload" reloaded)
     (el-run-kill reloaded)))
 (let ((buffer (el-run-start-the-ides-way)))
   (with-current-buffer buffer
     (map-put! agent-shell--state :session '((:id . "session-1")))
     (map-put! agent-shell--state :supports-session-fork t)
     (setq el-run-initialize nil)
     (agent-shell-fork))
   (let ((forked (seq-find (lambda (b) (and (not (eq b buffer))
                                            (eq (buffer-local-value 'major-mode b) 'agent-shell-mode)))
                           (buffer-list))))
     (el-run-report "A session forked with agent-shell-fork" forked)
     (el-run-kill forked)
     (el-run-kill buffer)))
 (setq agent-shell-elicitation--experimental-feature-enabled t)
 (let ((buffer (let ((agent-shell-session-strategy 'new))
                 (agent-shell-start :config (el-run-config)))))
   (el-run-report "Switch set globally" buffer)
   (el-run-kill buffer)))
#+end_src
