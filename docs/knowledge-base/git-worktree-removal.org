#+TITLE: Removing a Git Worktree — Reference
#+STARTUP: overview

Not a project document. This records how git behaves when a worktree and its
branch are removed, as established by runs of git 2.54.0 and GNU Emacs 30.2 on 2026-10-08.

*What it establishes.* =git worktree remove= removes a worktree whose only
untracked files are excluded through =info/exclude= or ignored through
=.gitignore=, and refuses one holding untracked files that are not ignored, or
modified tracked files, unless given =--force=. =git branch -d= refuses a branch
while a worktree has it checked out, and deletes a branch merged into the
current branch once its worktree is detached or removed. An Emacs buffer
modified in memory leaves a lock file in the worktree, which makes
=git worktree remove= refuse it until the buffer is marked unmodified.

* git worktree remove removes a worktree holding only excluded or ignored files

In the run below, the worktrees =excluded= (a =.trf/= directory excluded
through =info/exclude=) and =ignored= (a =.trf/= directory and a =build.log=
matching =.gitignore=) are removed, exit 0.

* git worktree remove refuses a worktree holding untracked or modified files

In the run below, the worktrees =untracked= (an untracked =new.el=) and
=modified= (an edit to the tracked =.gitignore=) are refused, exit 128, with
"contains modified or untracked files, use --force to delete it", and stay in
=git worktree list=.

* git branch -d refuses a branch checked out in a worktree

In the run below, =git branch -d trf/excluded= is refused, exit 1, while the
worktree =excluded= has the branch checked out, and deletes it once that
worktree is removed.

* git branch -d deletes a merged branch once its worktree is detached

In the run below, =trf/merged= holds a commit that =main= has merged with
=--no-ff=. =git branch -d trf/merged= is refused, exit 1, while the worktree
=merged= has it checked out; once =git checkout --detach= has detached that
worktree, the branch is deleted, exit 0, and the detached worktree is then
removed, exit 0.

* git worktree remove refuses a worktree holding a modified buffer's lock file

In the second run below (GNU Emacs 30.2), an Emacs buffer visiting
=widget.el= in a worktree and modified in memory leaves the lock file
=.#widget.el= there, an untracked file, so =git worktree remove= refuses it,
exit 128. Once =set-buffer-modified-p= has marked the buffer unmodified, the
lock file is gone and the worktree is removed, exit 0.

* The run

Run with =bash kb-run.sh <empty directory>=; the script writes that directory
as =<tmp>= in its output.

#+begin_src sh
set -u
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1
export GIT_AUTHOR_NAME=a GIT_AUTHOR_EMAIL=a@b GIT_COMMITTER_NAME=a GIT_COMMITTER_EMAIL=a@b
tmp=$(cd "$1" && pwd -P)
run() { echo "\$ $*"; "$@"; echo "exit $?"; }
main() {
  cd "$tmp"
  git --version
  git init --quiet --initial-branch=main root && cd root
  echo '*.log' > .gitignore && git add .gitignore && git commit --quiet --message init
  echo '/.trf/' >> .git/info/exclude
  for case in excluded ignored untracked modified merged; do
    git worktree add --quiet -b "trf/$case" "../$case" HEAD
    mkdir ../$case/.trf && echo state > ../$case/.trf/root
  done
  echo log > ../ignored/build.log
  echo new > ../untracked/new.el
  echo '*.tmp' >> ../modified/.gitignore
  echo work > ../merged/work.el
  git -C ../merged add work.el && git -C ../merged commit --quiet --message work
  git merge --quiet --no-ff --no-edit trf/merged
  run git branch -d trf/excluded
  for case in excluded ignored untracked modified; do
    run git worktree remove "../$case"
  done
  run git branch -d trf/excluded
  run git branch -d trf/merged
  run git -C ../merged checkout --quiet --detach
  run git branch -d trf/merged
  run git worktree remove ../merged
  run git worktree list
}
main 2>&1 | sed "s|$tmp|<tmp>|g"
#+end_src

#+begin_example

$ git branch -d trf/excluded

exit 0

* The second run

Run with =bash lock-run.sh <empty directory>=; the script writes that directory
as =<tmp>= in its output.

#+begin_src sh
set -u
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1
export GIT_AUTHOR_NAME=a GIT_AUTHOR_EMAIL=a@b GIT_COMMITTER_NAME=a GIT_COMMITTER_EMAIL=a@b
tmp=$(cd "$1" && pwd -P)
main() {
  cd "$tmp"
  emacs --version | head -1
  git init --quiet --initial-branch=main root && cd root
  echo one > widget.el && git add widget.el && git commit --quiet --message init
  git worktree add --quiet -b trf/work ../work HEAD
  emacs -Q --batch --eval '(progn
    (find-file "../work/widget.el")
    (insert "edit\n")
    (princ (format "modified: %s\n" (buffer-modified-p)))
    (princ (shell-command-to-string "git -C ../work status --porcelain --untracked-files=all"))
    (princ (shell-command-to-string "git worktree remove ../work; echo exit $?"))
    (set-buffer-modified-p nil)
    (princ (format "modified: %s\n" (buffer-modified-p)))
    (princ (shell-command-to-string "git -C ../work status --porcelain --untracked-files=all"))
    (princ (shell-command-to-string "git worktree remove ../work; echo exit $?")))'
}
main 2>&1 | sed "s|$tmp|<tmp>|g"
#+end_src
