* ADR-9 Apply the machine settings as ACP session config options

** Context

ADR-2 Talk to machines over ACP has the IDE reach machines only through ACP.
ACP lets an AI program advertise session config options, each in a category
such as model, mode or thought level, and lets the client set them on a
session. Claude Code takes its model, permission mode and thinking effort this
way, ignores a permission mode of auto from a target product's own settings,
and can report back a value other than the one set.

** Decision

Before a machine is told anything more, the IDE sets the model, permission mode
and thinking effort on its ACP session as the session config options of the
model, mode and thought level categories, and reads back the value the AI
program reports for each.

** Status

Accepted.

** Consequences

- Any AI program that advertises these config options takes the machine
  settings.
- A value the AI program does not advertise, refuses, or reports back changed
  is a machine setting it does not offer.
- Nothing is written into the target product's own settings for the AI
  program.
