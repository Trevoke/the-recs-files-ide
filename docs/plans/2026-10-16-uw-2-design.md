# UW-2: Choose the machine settings — design

Records this slice implements:

- UW-2: Choose the machine settings
- UW-1: Turn record changes into code, extension 3-5b
- F-4: Choose the machine settings
- F-5: Find the IDE's commands in The Recs Files menu
- MSG-14: Machine setting not offered
- ADR-8: Keep the machine settings as Emacs customization options
- ADR-9: Apply the machine settings as ACP session config options

## Decisions left to the design

1. **Four options in a Customize group "machine settings"** inside `trf`:
   `trf-ai-program` (the agent-shell config identifier, `claude-code`),
   `trf-model` (`opus`), `trf-permission-mode` (`auto`),
   `trf-thinking-effort` (`medium`). `trf-ai-program-config` is retired; step 3
   no longer asks for the AI program.
2. **The model's default is `opus`, not `claude-opus-5-5`.** Claude's adapter
   accepts `claude-opus-5-5` but reports it back as `opus` (named "Opus 5.5"),
   which ADR-9 would take as a setting not offered.
3. **`custom-file`** is `custom.el` in `$XDG_CONFIG_HOME/recs-files-ide/`, or
   `~/.config/recs-files-ide/`, set in `ide/init.el` and loaded at start.
4. **`trf-machine-settings`** on `C-c r s` opens the group.
5. **The machine settings are applied at every session start, a resumed one
   included**, once the session is ready and before the IDE sends its message:
   model, then permission mode, then thinking effort. Each: find the session's
   config option of the category (model, mode, thought_level), check the value
   is offered, send `session/set_config_option`, read the value back. Any
   failure stops the machine before it is told anything, with MSG-14.
6. **agent-shell's own default model and mode are switched off** for the
   machines' configs, so they do not fight the IDE's.
7. **The Recs Files menu** is a keymap on `global-map`'s menu bar after Tools
   (`keymap-set-after`), in `lisp/trf-menu.el`: implement, accept, reject,
   continue, a separator, machine settings. Keys shown come from the global
   bindings.
8. **`.gitignore`** gains `ide/agent/`.

## Facts the design rests on

From a probe of `@agentclientprotocol/claude-agent-acp` 0.91.0 and the source
of agent-shell v0.86.2 and acp.el v0.15.1 (to be recorded in the knowledge
base by the first task):

- The adapter advertises config options `mode` (ids `default`, `acceptEdits`,
  `plan`, `auto`, `bypassPermissions`), `model` (`default`, `opus`, `sonnet`,
  `haiku`, …) and `effort` (category `thought_level`: default, low, medium,
  high, xhigh, max). It advertises no `models` at session start, and
  `session/set_model` is "Method not found".
- `auto` from a project's `.claude/settings.json` or `settings.local.json` is
  dropped; set at runtime it applies. For a model without auto mode, `auto`
  becomes `acceptEdits`.
- agent-shell 0.86.2 sends `session/set_config_option`, and skips a default
  config value the session does not advertise.

## Known gaps

- Customize cannot list the values an AI program offers; the record keeper
  types them (ADR-8 §Consequences).
- When Anthropic moves `opus` to a newer model, the default follows it.
