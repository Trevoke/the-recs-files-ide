#+TITLE: Ubiquitous Language

Each term is defined within its bounded context, as named in the vision.

* Records

- record :: one decision important to the delivery or maintenance of the target
  product, under a unique identifier, in words the record keeper has agreed to.
- projection :: the records of one form, such as the user workflows or the
  message catalog.
- record keeper :: the person who creates, edits and maintains the records.
- record changes :: the edits to records and to the vision not yet implemented.
- target product :: the product the records are about.

* Implementation

- implementation plan :: the steps for turning record changes into code that
  the planning machine writes and the executing machine follows.
- record implementation report :: for each of the record changes, the tests that
  cite it and their results.
- reconciled :: the codebase is reconciled with a record when the truth of the
  record is reflected in the codebase.
- implemented :: said of record changes once the record keeper has accepted
  their record implementation report into the codebase.
- codebase :: the target product's code that the record keeper has accepted.
- machine :: an AI program the IDE has put to one kind of work, through the
  instructions it gives and the devices it configures it with.
- device :: a tool a machine uses, such as the shell, the file system, the test
  runner or a skill.
- implementation workflow :: the brainstorming machine, the planning machine
  and the executing machine, run one after another on the record changes.
- brainstorming machine :: the machine that settles with the record keeper how
  the record changes are to be implemented, using the brainstorming skill.
- planning machine :: the machine that writes the implementation plan, using
  the writing-plans skill.
- executing machine :: the machine that turns record changes into code by
  following the implementation plan, using the executing-plans skill.
- reconciliation assessor :: the machine that assesses whether the codebase is
  reconciled with each of the record changes, and writes the record
  implementation report.
