* F-3 Start a stopped machine again on its work in progress

Takes: a work in progress whose machine stopped before finishing.

Produces: that machine at work again on the work in progress as it stands, and
the rest of the implementation workflow and the reconciliation assessor after
it, as far as a record implementation report.

** Rules

- The IDE starts the machine that stopped with the instructions it gave it
  first, including the paths the machine before it produced.
- Outside a work in progress whose machine stopped since the IDE last started,
  the IDE gives MSG-11: No stopped machine to start again.
- Before starting the machine, the IDE offers to save each file of the work in
  progress with unsaved edits; the machine works from what the record keeper
  saves, and unsaved edits are left as they are.

** Next

The record keeper accepts or rejects the record implementation report.
