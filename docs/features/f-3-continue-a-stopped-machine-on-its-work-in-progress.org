* F-3 Continue a stopped machine on its work in progress

Takes: a work in progress whose machine stopped before finishing, and what the
record keeper tells that machine when it was told something before it stopped.

Produces: that machine at work again on the work in progress as it stands,
with everything it was told and said before it stopped, asking the record
keeper its questions as before, and followed by the rest of the implementation
workflow and the reconciliation assessor after it, as far as a record
implementation report.

** Rules

- When the machine was told something before it stopped, the IDE asks the
  record keeper what to tell it, and gives it to the machine as its next
  message.
- When the machine stopped before it was told anything, the IDE starts it with
  the instructions it gives it at first, including the paths the machine
  before it produced, and asks the record keeper nothing.
- Outside a work in progress whose machine stopped since the IDE last started,
  the IDE gives MSG-11: No stopped machine to continue.
- When the machine cannot be continued, the IDE gives MSG-12: Machine cannot be
  continued, and keeps the work in progress.
- Before continuing the machine, the IDE offers to save each file of the work
  in progress with unsaved edits; the machine works from what the record keeper
  saves, and unsaved edits are left as they are.
- Restarting the machine at work asks the record keeper whether to stop it; on
  yes, the IDE stops it and continues it; on no, the machine carries on at work.
- Restarting a stopped machine continues it.

** Next

The record keeper accepts or rejects the record implementation report.
