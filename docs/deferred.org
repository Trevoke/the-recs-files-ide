#+TITLE: Deferred

Drafts agreed in conversation and waiting their turn. Nothing here is a record:
no identifier here is reserved, and nothing may cite this file.

* Amend a record during implementation (user workflow)

Returns to UW-1 as extension 4a, "An answer changes a record", when written.

- Scope :: the IDE (black-box)
- Level :: user goal
- Primary actor :: record keeper

** Stakeholders and interests

- Record keeper :: the codebase is reconciled with the record as amended.
- Target product :: no record changes without the record keeper's say.

** Precondition

The implementing machine is implementing record changes (UW-1 Turn record changes into code).

** Minimal guarantee

The work done so far is kept.

** Success guarantee

The implementing machine implements against the amended records.

** Trigger

An answer to the implementing machine's question changes a record.

** Main success scenario

1. Implementing machine stops implementing.
2. Record keeper amends the record.
3. IDE adds the amended record to the record changes.
4. Implementing machine assesses whether the implementation plan holds for the record changes;
   it holds.
5. Implementing machine resumes implementing.

** Extensions

- 4a. The implementation plan no longer holds :: implementing machine
  makes a new implementation plan for the same goal from the record changes; continues at
  step 5.
